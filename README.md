# Student Grade Tracker

## 📌 Project Overview
Student Grade Tracker is a Java-based console application developed as part of my CodeAlpha Java Programming Internship.

The application allows users to add student details, calculate grades, view class statistics, search students, and identify top performers.

## 🚀 Features
- Add student details
- Display all students
- Calculate class statistics
- Calculate average, highest and lowest marks
- Search student by roll number
- Display Top 3 performers
- Grade calculation
- Pass/Fail status
- Input validation
- Menu-driven console interface

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Collections
- Comparator
- Scanner

## 📊 Grade System

| Marks | Grade |
|------|------|
| 90–100 | A+ |
| 80–89 | A |
| 70–79 | B |
| 60–69 | C |
| 50–59 | D |
| Below 50 | F |

## ▶️ How to Run

1. Open the project in Eclipse IDE.
2. Open `StudentGradeTracker.java`.
3. Run the Java program.
4. Follow the menu displayed in the console.
